# ETF Elite｜菁英交易助手（手机网页原型）

## 当前版本
- 手机优先的 PWA 页面，可在浏览器中打开并尝试“添加到主屏幕”。
- 首页、信号、持仓记录、设置四个模块。
- 可本地记录你在东方财富比赛中实际完成的模拟成交，并导出 JSON。
- **当前不含真实行情，不生成真实买卖信号，不会自动下单。** 首页明确标注演示状态。

## 为什么没有直接连行情/自动交易？
1. 需要先选定稳定、合规、可用的行情数据源，并确认 ETF 实时行情权限与延迟。
2. 云端自动更新需要部署后端服务和定时任务；需要由用户选择/授权部署平台。
3. 东方财富比赛是否开放受支持的模拟交易 API 尚未确认，不能把模拟下单能力当作已具备。

## 本地预览
将整个文件夹放到支持静态网页的托管服务，或在电脑上用本地静态服务器预览。PWA 的安装与 Service Worker 通常要求 HTTPS 或 localhost。

## 下一阶段建议
- 使用可靠数据源拉取 ETF 日线行情。
- 建立候选池与数据质量校验。
- 编写动量/趋势评分、手续费模型和回测。
- 加入云端定时任务与推送。
- 仅在平台明确提供支持的接口时，研究自动模拟下单。

## 安全原则
不要把东方财富账号密码、验证码、支付信息或会话 Cookie 填入此项目；不要通过模拟点击或非官方接口绕过平台限制。
