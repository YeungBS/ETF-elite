候选池设置

本地候选池只保存在当前浏览器，不会自动修改云端观察列表。 要更改每日排名范围，还需修改仓库中的 config/watchlist.txt。

买入建议规则

积极信号：收盘价高于 MA20、MA20 高于 MA60、20 日涨幅为正、5 日涨幅不为负。

风险信号：收盘价低于 MA20 且 MA20 低于 MA60，或者 20 日涨幅不高于 -8%。

其余情况为观察信号。阈值仅用于初步筛选，尚未经过完整回测。

数据来源与局限

页面读取仓库中的 data/results.json。数据是否正确取决于后端接口、行情日期和计算逻辑。 GitHub Actions 显示成功不代表行情一定准确；如果行情过期、异常或不完整，请暂停参考买入建议。
